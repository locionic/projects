We have arrived at the final, defining milestone of the course. Up to this point, we have operated in interactive development mode, using the chat trigger to test our tools.

Now, we flip the switch to make our Executive Assistant **100% autonomous**. Every morning at 7:00 AM, without touching a single button, the assistant will wake up, inspect your calendar, gather weather and web intelligence, and deliver your morning briefing across Gmail and Telegram.

```
[ Schedule Trigger (Every morning at 07:00 AM) ]
                        │
                        ▼
             [ Planner AI Agent Node ]
               ├── Prompt: Autonomous Daily Directive (Role, Task, Tools, Rules)
               ├── Chat Model: OpenAI GPT-4o-mini (Temp: 0.2)
               ├── Memory: Window Buffer Memory (Static Session ID: day_planning_session)
               └── Tools:
                     ├── 1. Google Calendar (Fetch agenda)
                     ├── 2. OpenWeatherMap (Location forecast)
                     ├── 3. SerpAPI (Company research)
                     ├── 4. Gmail (HTML daily report)
                     └── 5. Telegram (Mobile push alert)
```

## Step 1: Replace the Chat Trigger with the Schedule Trigger

1. On your canvas, select the `When chat message received` node.
2. In its settings, toggle the node to **Disabled** (or delete the connection spline to the AI Agent).
3. Click the **+** icon to add a new trigger node.
4. Search for **Schedule** and select **Schedule Trigger** (under Triggers).
5. Rename the node to:
   ```
   Daily 7am Cron Trigger
   ```
6. Configure the schedule trigger rules:
   - **Trigger Interval**: `Days`
   - **Days Between Triggers**: `1`
   - **Trigger at Hour**: `7am (07:00)`
   - **Trigger at Minute**: `0`
7. Wire the output of `Daily 7am Cron Trigger` directly into the input of `Planner AI Agent`.

## Step 2: Configure the Autonomous Prompt (Define Below)

When the workflow ran via the Chat Trigger, the prompt was supplied interactively by you (`chatInput`). In scheduled cron mode, there is no user typing in a chat window. The agent must receive its prompt automatically.

1. Double-click the `Planner AI Agent` node.
2. Under **Prompt**, change **Source for Prompt** from *Connected Chat Trigger Node* to:
   ```
   Define Below
   ```
3. Enter the comprehensive autonomous production prompt:

```text
You are an Autonomous Executive Assistant running on a daily automated schedule.

YOUR TASK:
Compile and dispatch the daily executive intelligence briefing for TODAY ({{ $now.format('cccc, LLLL d, yyyy') }}) and TOMORROW.

EXECUTION SEQUENCE:
1. Query Google Calendar using fetch_calendar_events for events between {{ $today.toISO() }} and {{ $today.plus({ days: 2 }).toISO() }}.
2. If any meeting has a physical location, call get_weather_forecast for that city.
3. If any event title or description mentions an external company (e.g. interviews, partnerships), call serpapi_web_search to find the latest 2-3 news headlines.
4. Call send_email_report to deliver the complete briefing formatted as a clean HTML table with weather alerts and research bullet points.
5. Call send_telegram_alert to deliver an urgent, concise mobile summary of the key meeting times and weather.

CONSTRAINTS:
- Do not ask clarifying questions; execute all necessary tool calls autonomously.
- If the calendar contains zero events, send a short confirmation via Telegram: "Your schedule is clear for today and tomorrow. Have a productive day!"
```

## Step 3: Resolving the Headless Session ID Bug

If you click **Execute workflow** right now, n8n may throw a red execution error on the `Window Buffer Memory` node:
> `Error: Missing session ID for memory`

### Why This Error Happens
During chat mode, the Chat Trigger automatically generated a dynamic `sessionId` for each browser session. The Memory node expected that key. With the Chat Trigger disabled, `sessionId` evaluates to `undefined`.

### The Fix
1. Double-click the **Window Buffer Memory** node.
2. Change **Session Key** from *From Input* to **Define Below**.
3. Enter a static persistent session identifier:
   ```
   executive_assistant_session
   ```
4. Click Save.

## Step 4: Live Execution Simulation

Click **Execute workflow** in the canvas editor to simulate the scheduled run:

1. The Schedule Trigger fires.
2. The AI Agent receives its autonomous prompt.
3. Watch the green checkmarks illuminate across the canvas:
   - Calendar events retrieved.
   - Weather forecast queried for San Francisco.
   - SerpAPI research executed for Anthropic.
   - HTML briefing delivered to your Gmail inbox.
   - Mobile notification received on your phone via Telegram.
4. Open your email and Telegram: both reports have arrived in flawless synchronization!

## Step 5: Activate Production Mode

1. In the upper right corner of the n8n canvas, toggle the **Active** switch from off to **on**.
2. Click **Save**.
3. Inspect the **Executions** tab: your workflow is now running live on the background daemon. Every morning at 7:00 AM, your assistant will wake up and handle your morning briefing automatically.

<Exercise title="Design a Human-in-the-Loop Confirmation Gate">
Suppose you want to add a sixth tool: `reschedule_calendar_event`. 
Because moving a meeting impacts other people, you do not want the agent to reschedule meetings without your permission.

How can you implement a human confirmation gate in n8n?

<SolutionToggle>
Use n8n's **Wait Node** with webhook approval:
1. When the agent determines a meeting should be rescheduled, it does not call the update tool directly.
2. It sends a message to Telegram with two inline buttons: **[Confirm Reschedule]** and **[Cancel]**, linked to a unique n8n webhook URL.
3. The workflow pauses execution at the `Wait` node.
4. When you tap **Confirm** on your phone, the webhook resumes the workflow and executes the calendar update tool. This represents true enterprise Human-in-the-Loop agent architecture.
</SolutionToggle>
</Exercise>
