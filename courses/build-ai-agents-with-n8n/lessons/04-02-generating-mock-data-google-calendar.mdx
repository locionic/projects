When developing an autonomous agent that reads personal or corporate calendar events, testing against your primary real-world calendar introduces two major issues:
1. **Privacy & Clutter**: Test runs may generate hundreds of API logs containing private personal appointments.
2. **Non-Reproducible Test Conditions**: If your real calendar has zero events tomorrow, the agent will have nothing to process, making it impossible to verify downstream weather or web search tools.

In this lesson, we create an isolated, dedicated Google Calendar populated with realistic test scenarios.

## Step 1: Create a Dedicated Test Calendar

1. Open [calendar.google.com](https://calendar.google.com) in your browser.
2. In the left sidebar, locate **Other calendars** and click the **+** (Add other calendars) icon.
3. Select **Create new calendar**.
4. Configure the calendar settings:
   - **Name**: `AI Agent Day Planner Calendar`
   - **Description**: `Isolated test calendar for n8n AI agent workflows`
   - **Time Zone**: Set to your local time zone.
5. Click **Create calendar**.

```
Google Calendar Left Sidebar:
My calendars:
├── Personal (Primary)
└── AI Agent Day Planner Calendar  <── Use this isolated calendar for all testing!
```

## Step 2: Populate Realistic Mock Events

To thoroughly test our agent's ability to extract physical locations and identify corporate research targets, populate tomorrow's date with three specific events:

### Event 1: The Corporate Job Interview
- **Title**: `Job Interview with Anthropic`
- **Time**: `10:00 AM - 11:30 AM`
- **Location**: `Virtual / Google Meet`
- **Description**: `Final stage technical interview for Senior AI Systems Architect role. Panel includes research leads.`
- *Testing Purpose*: Tests whether the agent identifies "Anthropic" as an organization and autonomously triggers SerpAPI to retrieve recent company headlines.

### Event 2: The Physical Lunch Meeting
- **Title**: `Coffee with Paul`
- **Time**: `02:00 PM - 03:00 PM`
- **Location**: `Starbucks, Market St, San Francisco, CA`
- **Description**: `Discussing seed stage funding terms and product roadmap.`
- *Testing Purpose*: Tests whether the agent extracts "San Francisco" from the location string and passes it to the OpenWeatherMap tool.

### Event 3: The Internal Product Review
- **Title**: `Weekly Product Sprint Review`
- **Time**: `04:30 PM - 05:30 PM`
- **Location**: `Conference Room B (HQ)`
- **Description**: `Reviewing sprint velocity and blockers with internal engineers.`
- *Testing Purpose*: Tests whether the agent recognizes internal meeting rooms and does not waste API tokens searching Google or weather for internal conference rooms.

<Callout type="info" title="Downloadable iCalendar (.ics) Alternative">
If you prefer not to enter events manually, you can export or create a `.ics` text file and import it directly into your Google Calendar settings under **Settings -> Import & export**.
</Callout>

<Exercise title="Identify Contextual Edge Cases">
Consider an event with the title: `"Dinner with Sarah at French Laundry"`.
If the user forgot to enter a city in the location field, how should an intelligent agent handle the missing location?

<SolutionToggle>
An intelligent agent with search capabilities will recognize that "French Laundry" is a world-renowned restaurant located in Yountville, California. 

If the weather tool fails with just "French Laundry", the agent can execute a rapid SerpAPI search: `"French Laundry restaurant location city"`, extract `"Yountville, CA"`, and subsequently query OpenWeatherMap for Yountville weather. This demonstrates the power of multi-tool agent loops.
</SolutionToggle>
</Exercise>
