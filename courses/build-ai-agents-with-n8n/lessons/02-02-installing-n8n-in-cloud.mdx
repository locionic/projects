For developers who want to bypass server management, reverse proxies, and Docker maintenance, **n8n Cloud** provides an instant, fully managed environment. In this lesson, we walk through provisioning your cloud instance and configuring its core settings.

## Provisioning Your Instance

1. Navigate to [n8n.io](https://n8n.io) and click **Get Started for Free**.
2. Register your account using your business email or GitHub login. Every new account receives a 14-day free trial that includes **1,000 workflow executions**.
3. **Select Your Instance Name**: Pay careful attention to the instance name field. Your chosen name forms your unique cloud subdomain:
   ```
   https://<your-subdomain>.app.n8n.cloud
   ```
4. Complete the brief onboarding survey (team size, automation goals) and click **Create Instance**.
5. Instance provisioning takes approximately 60 to 90 seconds while n8n provisions isolated container resources, database storage, and SSL certificates.

### What Counts as an Execution?
In n8n Cloud billing, an **execution** represents one complete run of a workflow from trigger to final node. 
- If a webhook fires and executes 10 nodes across your workflow, that counts as **one single execution**.
- Manual test runs executed by clicking "Test step" or "Test workflow" in the canvas do **not** count toward your production quota during normal testing.
- If an agent ReAct loop calls 4 tools before generating a final response, the entire multi-step interaction is counted as **one execution**.

<Callout type="info" title="Execution vs Task-Based Billing">
This is a critical cost advantage of n8n Cloud compared to other SaaS automation tools. Platforms that bill per individual task charge you for every single node in the workflow. n8n bills per completed workflow execution, regardless of how many nodes or internal tool calls execute.
</Callout>

## Upgrading and Version Maintenance

Even though n8n Cloud is fully managed, platform updates are not forced on you unpredictably. This protects production workflows from unexpected breaking changes:

- When a new version of n8n is released, a notification banner appears in the bottom left sidebar under **What is New**.
- You can inspect release notes, verify community node compatibility, and trigger the upgrade with a single click during your preferred maintenance window.

## One-Click Cloud VPS Alternatives

If you prefer self-hosting with zero manual Docker scripting, Andrei highlights two reliable cloud alternatives:

1. **Hostinger VPS with n8n Template**: Hostinger provides an Ubuntu 24.04 VPS template that provisions n8n inside Docker with Traefik SSL and automatic container restarts pre-configured.
2. **Render.com Web Service**: Render allows you to deploy the official n8n Docker image directly on their managed cloud application runner with an attached persistent disk.

- **Ad-hoc runs**: 10 runs/day * 30 days = 300 executions/month.
