To design reliable AI agent workflows, you must first master the execution mechanics of n8n. In this lesson, we examine how data enters a workflow, transforms across nodes, and reaches destination systems.

## Canvas Navigation and Productivity

The n8n workflow editor is an infinite 2D canvas. Navigating efficiently accelerates your development:

- **Pan the Canvas**: Hold `Spacebar` and drag with your mouse, or hold `Ctrl` / `Cmd` and scroll horizontally/vertically.
- **Zoom In / Out**: Hold `Ctrl` / `Cmd` and scroll your mouse wheel, or use the `+` and `-` controls in the bottom right corner.
- **Select Multiple Nodes**: Hold `Shift` and drag a selection bounding box over the nodes.
- **Tidy Up**: Click the **Tidy up** button in the canvas controls (or press `Shift + A`). n8n automatically re-aligns all nodes, straightens connection splines, and removes visual clutter.
- **Copy Nodes as JSON**: Select any node or group of nodes and press `Ctrl + C` (or `Cmd + C`). The entire node configuration is copied to your operating system clipboard as formatted JSON.

## The Five Core Building Blocks

Every n8n automation consists of five foundational elements:

```
[ Trigger Node ] ───> [ Transformation Node ] ───> [ Condition Node (IF) ] ───> [ Action Node ]
                                                           │
                                                           └───> [ Alternative Action ]
```

1. **Workflow**: The complete visual pipeline representing an automated process.
2. **Trigger**: The entry point that starts execution. Triggers can be **event-driven** (Webhook, Form Submission, Email Received) or **time-driven** (Cron Schedule, Interval).
3. **Nodes**: Discrete operational stations. Each node performs one job: querying a database, invoking an LLM, transforming data, or making an HTTP request. Think of nodes as stations along a factory conveyor belt.
4. **Expressions**: Dynamic JavaScript templates enclosed in double curly braces `{{ ... }}` that extract or compute values from previous nodes at runtime.
5. **Conditions & Routers**: Logic splitters (IF nodes, Switch nodes) that direct data items along different paths based on boolean evaluations.

## The Underlying Data Model: The Item Array Contract

Understanding n8n's internal data model is essential for avoiding bugs. In n8n, data passed between nodes is always an **array of objects**, where each element conforms to the following contract:

```json
[
  {
    "json": {
      "id": 101,
      "email": "sarah@example.com",
      "company": "Acme Corp",
      "tier": "enterprise"
    },
    "binary": {}
  },
  {
    "json": {
      "id": 102,
      "email": "marcus@example.com",
      "company": "Beta LLC",
      "tier": "starter"
    },
    "binary": {}
  }
]
```

### The Conveyor Belt Behavior (Item-Level Looping)
Notice that each item has a `json` key containing key-value data, and an optional `binary` key containing raw file streams (images, PDFs).

When a node receives an array of 5 items, **it automatically executes once for each item in the array**. You do not need to write explicit for-loops. If you pass an array of 10 customer records to a Slack node, the Slack node will post 10 individual messages sequentially unless you explicitly aggregate them into a single item.

## Expression Syntax and Dynamic Variables

Expressions allow downstream nodes to reference data generated upstream:

- `{{ $json.field_name }}`: References a field from the immediate previous node for the current item.
  - Example: `{{ $json.email }}` resolves to `"sarah@example.com"`.
- `{{ $('NodeName').item.json.field_name }}`: References a field from a specific earlier node named `NodeName`.
- `{{ $now.toISO() }}`: Returns the current execution timestamp in ISO 8601 format (`2026-09-15T14:30:00.000Z`).
- `{{ $now.format('yyyy-MM-dd') }}`: Uses Luxon formatting to produce a formatted date string (`2026-09-15`).

```javascript
// Examples of dynamic expressions inside node parameters
"Hello {{ $json.first_name }}, your order #{{ $json.order_id }} has shipped!"

// Ternary logic inside an expression
"Priority: {{ $json.tier === 'enterprise' ? 'URGENT' : 'STANDARD' }}"
```

<Callout type="warning" title="Expression Case Sensitivity">
Field names in n8n expressions are strictly case-sensitive. If an incoming webhook sends `{{ $json.UserID }}`, referencing `{{ $json.userId }}` will evaluate to `undefined`. Always inspect the Schema pane on the left side of the node editor to verify exact key casing.
</Callout>

<Exercise title="Debug an Expression Reference">
A developer connects a Google Sheets trigger to an Email node. In the Email node's recipient field, they write:
`{{ $json.customer_email }}`

However, when testing the node, the field evaluates to `undefined`, even though the spreadsheet contains an email column. What are the two most common causes?

<SolutionToggle>
1. **Header Name Mismatch**: Google Sheets headers often have capitalization or spaces. If the spreadsheet column is titled `Customer Email`, the correct expression is `{{ $json["Customer Email"] }}`.
2. **First Row Offset**: If the sheet has an empty row before the header row, n8n treats the empty row as the column titles. Always verify the incoming payload in the Input data pane on the left.
</SolutionToggle>
</Exercise>
