When preparing for an executive meeting, job interview, or sales pitch, knowing the other party's latest announcements, press releases, and product launches gives you a decisive advantage. Standard LLMs cannot access real-time web news beyond their training cutoffs.

In this lesson, we connect **SerpAPI** (Google Search API) to our agent's Tools port.

```
                  [ Planner AI Agent ]
                    ├── Model: OpenAI Chat Model
                    ├── Memory: Window Buffer Memory
                    └── Tools (Orange Port)
                          ├── [ Google Calendar Tool ] (Discovers "Interview with Anthropic")
                          ├── [ OpenWeatherMap Tool ]  (Weather for meeting locations)
                          └── [ SerpAPI Search Tool ]  (Searches "Anthropic recent news headlines")
```

## Step 1: SerpAPI Account and Key Setup

1. Navigate to [serpapi.com](https://serpapi.com).
2. Register for a free account. SerpAPI provides **100 free searches per month**, which is more than enough for personal daily briefings and testing.
3. From your dashboard, copy your private **API Key**.

## Step 2: Attach the SerpAPI Tool Node

1. On your canvas, locate the `Planner AI Agent` node.
2. Click the **+** icon beneath the **Tools** port (orange port).
3. Search for **SerpAPI** and select the **SerpAPI** tool node.
4. Rename the node to:
   ```
   serpapi_web_search
   ```
5. Configure credentials:
   - Create a new credential under **SerpAPI API**.
   - Paste your API key and click **Save**.
6. Parameter settings:
   - **Tool Description**: Leave set to **Set Automatically**. The schema informs the LLM that this tool queries Google Search and returns top organic result titles, snippets, and source links.

## Step 3: Testing Live Research Chaining

Let's test whether the agent can autonomously research an interview target found in our calendar:

1. Open the chat widget in n8n.
2. Enter the prompt:
   > *"Find the latest news headlines for the company I am interviewing with tomorrow."*
3. Watch the reasoning logs execute in real time:
   - **Step 1 (`fetch_calendar_events`)**: Discovers event *"Job Interview with Anthropic"*.
   - **Step 2 (Reasoning)**: Identifies *"Anthropic"* as the target company.
   - **Step 3 (`serpapi_web_search`)**: Formulates search query: `{ "q": "Anthropic company latest news headlines 2026" }`.
   - **Step 4 (Observation)**: Receives search snippets regarding Anthropic's frontier model releases, enterprise safety research, and recent partner initiatives.
   - **Step 5 (Final Response)**:
     > *"You are interviewing with Anthropic tomorrow at 10:00 AM. Here are their latest news headlines to help you prepare:*
     > 
     > *1. **Claude 3.5 Sonnet Ecosystem Updates**: Anthropic expanded enterprise computer use capabilities and function-calling throughput.*
     > *2. **AI Safety & Constitutional AI**: Published new evaluations on model alignment and multi-agent coordination.*
     > *3. **Enterprise Expansion**: Major cloud providers expanded direct VPC hosting for Anthropic models.*
     > 
     > *Would you like me to draft talking points based on these developments?"*

<Callout type="info" title="Zero Hallucination Factuality">
Notice how SerpAPI grounds the LLM in current facts. The model is no longer relying on stale training weights; it cites real-world articles published within the last 24 to 48 hours.
</Callout>

<Exercise title="Manage Search Query Budget">
Because free tier SerpAPI accounts allow 100 searches per month, running 5 searches per morning would exhaust your monthly quota in 20 days. 

What rule can you add to the AI Agent System Message to conserve search queries?

<SolutionToggle>
Add an explicit search throttling constraint to the System Message:
```text
SEARCH CONSTRAINT:
Execute serpapi_web_search at most ONCE per daily briefing, and ONLY if an upcoming calendar event explicitly represents an external interview, pitch, or keynote with a named corporate organization. Do not execute web searches for routine internal meetings or recurring calendar blocks.
```
This guarantees the agent only spends search credits when high-value external context is required.
