In the previous lesson, our Reddit AI Content Intelligence pipeline worked reliably, with one significant usability defect: because n8n's execution engine operates on arrays of items, passing 5 summarized Reddit posts to Discord and Gmail resulted in **5 individual Discord pings and 5 separate emails**.

What we want instead is a **single, consolidated morning briefing** containing all 5 summaries merged neatly together.

In this lesson, we solve this problem by introducing a custom **Code** node written in JavaScript, and we leverage AI to refactor the workflow JSON.

## The 5-Message Problem Explained

Recall n8n's fundamental data contract:
When a node outputs an array of $N$ items, any connected downstream node executes $N$ times independently.

```
Current Execution Flow (Problematic):
[ Reddit Node (5 items) ] ───> [ OpenAI Node (5 items) ] ───> [ Discord Node ] (Sends 5 separate messages!)
                                                          └───> [ Gmail Node ]   (Sends 5 separate emails!)

Desired Execution Flow (Aggregated):
[ Reddit Node (5 items) ] ───> [ OpenAI Node (5 items) ]
                                          │
                                          ▼
                         [ Code Node: Format Combined Summaries ] (Merges 5 items into 1 item)
                                          │
                                          ├───> [ Discord Node ] (Sends 1 consolidated message)
                                          └───> [ Gmail Node ]   (Sends 1 consolidated email)
```

## Using AI to Refactor Workflow JSON

Because everything on the n8n canvas is stored internally as JSON, you can use modern LLMs (ChatGPT, Claude, Gemini) as workflow architectural assistants:

1. Select all nodes on your canvas (`Ctrl + A`).
2. Copy them to your clipboard (`Ctrl + C`).
3. Paste the JSON into your LLM chat prompt:

```text
You are an expert in n8n workflow architecture.
Here is the current workflow JSON:
[PASTE WORKFLOW JSON HERE]

PROBLEM:
This workflow retrieves 5 Reddit posts, summarizes them with OpenAI, and sends them to Discord and Gmail as 5 separate messages.

TASK:
1. Explain how to insert a JavaScript Code node between the OpenAI node and the notification nodes to aggregate all 5 summaries into a single combined report.
2. Provide the exact JavaScript code for the Code node.
3. Respond with the updated complete workflow JSON ready to be pasted back into n8n.
```

The LLM analyzes the graph connections, introduces a `Code` node named `Format Combined Summaries`, updates the connection splines, and returns the modified JSON.

## Writing the Custom Code Node in JavaScript

Let's examine the JavaScript code required inside the Code node. 

In n8n, a Code node can execute in one of two modes:
- **Run Once for Each Item**: Runs your script repeatedly for each individual item (does not solve our aggregation problem).
- **Run Once for All Items**: Receives the entire array of items via `$input.all()` and allows full aggregation. This is the mode we need.

Double-click the Code node, set the mode to **Run Once for All Items**, and enter the following JavaScript:

```javascript
// Retrieve all incoming items from previous OpenAI node
const items = $input.all();

// Build an array of formatted text blocks
const formattedSummaries = items.map((item, index) => {
  const data = item.json;
  const title = data.title || "Untitled Discussion";
  const summary = data.summary || data.text || "No summary available";
  const url = data.url || "#";
  const score = data.score || 0;
  
  return `### ${index + 1}. [${title}](${url}) (Upvotes: ${score})
${summary}
`;
});

// Join all summaries into a single cohesive markdown document
const header = `# Daily Reddit Intelligence Digest: r/startups
*Generated on ${new Date().toLocaleDateString()}*

---

`;
const fullReport = header + formattedSummaries.join("
---

");

// Return MUST strictly conform to the n8n item array contract:
// An array containing ONE object with a 'json' property
return [
  {
    json: {
      combined_summaries: fullReport,
      post_count: items.length,
      generated_at: new Date().toISOString()
    }
  }
];
```

### Critical Rules for n8n Code Nodes
1. **The Return Contract**: The code must always return an array of objects: `[{ json: { ... } }]`. If you return a raw string or bare object, n8n will throw an execution runtime error.
2. **Accessing Incoming Data**: Use `$input.all()` to access the full array of input items.
3. **Escaping and Formatting**: Ensure string concatenation preserves markdown line breaks (`

`) so downstream Discord and Slack nodes render headers cleanly.

## Wiring and Testing the Solution

1. Delete the direct connections between the OpenAI node and Discord/Gmail.
2. Connect the output of the OpenAI node to **Format Combined Summaries**.
3. Connect the output of **Format Combined Summaries** to both Discord and Gmail.
4. Update the Discord node message parameter to:
   ```
   {{ $json.combined_summaries }}
   ```
5. Click **Execute workflow**.

Inspect Discord and your email inbox: all five summaries are delivered in a single, professional intelligence digest!
