One of the greatest architectural advantages of building AI agents in n8n is **vendor neutrality**. The AI Agent node does not care whether its reasoning engine is hosted by OpenAI, Anthropic, Google, Mistral, or a local Ollama server running on your own GPU.

In this lesson, we explore how to swap the agent's brain, review model evaluation benchmarks, and connect Google Gemini.

## Modular Brain Architecture

Notice the decoupling in the n8n canvas:

```
                  [ Planner AI Agent ]
                            │
               ┌────────────┴────────────┐
               ▼ (Disconnect / Swap)     ▼
     [ OpenAI Chat Model ]    [ Google Gemini Chat Model ]
       (gpt-4o / mini)            (gemini-1.5-flash / pro)
```

The downstream tools (Calendar, Weather, Telegram) and the upstream Memory nodes remain completely unchanged. You simply detach one Chat Model sub-node and attach another.

## How to Choose an LLM: The LMSYS Arena

When selecting a model for production agents, avoid relying on marketing claims. Consult independent community benchmarks such as the **LMSYS Chatbot Arena** (`chat.lmsys.org`):

- **Reasoning & Tool Use**: Anthropic `claude-3-5-sonnet` and OpenAI `gpt-4o` consistently achieve top ratings for complex schema generation and multi-step planning.
- **Speed & High-Volume Processing**: Google `gemini-1.5-flash` and OpenAI `gpt-4o-mini` offer near-instant response latencies and lower token costs, making them ideal for high-throughput daily digests.
- **Temporal & Date Reasoning**: OpenAI models often show superior native handling of ISO 8601 timestamps and calendar math, as Andrei notes in the lecture.

## Connecting Google Gemini via Google AI Studio

Let's test swapping our OpenAI model for Google's Gemini:

1. **Obtain a Google AI Studio API Key**:
   - Navigate to [aistudio.google.com](https://aistudio.google.com).
   - Sign in with your Google account.
   - Click **Get API Key** in the top left menu.
   - Click **Create API Key** and copy your generated secret key.
2. **Add the Gemini Model Node in n8n**:
   - On your canvas, delete the connection spline between the `Planner AI Agent` and `OpenAI Summary Generator`.
   - Click the **+** icon on the purple Chat Model port of the agent.
   - Search for **Google Gemini Chat Model** and select it.
3. **Configure Gemini Credentials**:
   - Create a new credential under **Google Gemini API**.
   - Paste your API key from Google AI Studio and click Save.
   - Under **Model Name**, select `gemini-1.5-flash` (or `gemini-1.5-pro`).

## Testing Gemini Reasoning and Memory

Open the chat widget and execute a two-step factual test:

- **Turn 1**: *"What is the area of Paris in square kilometers?"*
  - Gemini responds with accurate geographical data (~105 sq km).
- **Turn 2**: *"What is the population for the same city?"*
  - Gemini uses Window Buffer Memory to recognize that "the same city" refers to Paris, outputting the census figures.

<Callout type="info" title="Why Andrei Recommends OpenAI for Calendar Agents">
While Gemini is fast and cost-effective, OpenAI models (`gpt-4o` and `gpt-4o-mini`) frequently demonstrate tighter adherence to date/time constraints when computing relative intervals (such as calculating "three days from now at 14:00 UTC"). We will use OpenAI for the remainder of the capstone.
</Callout>

<Exercise title="Compare Model Latency vs Cost">
You have a choice between `gpt-4o` ($2.50 / 1M input tokens) and `gpt-4o-mini` ($0.15 / 1M input tokens). 

Your agent runs 500 times per day, consuming 3,000 input tokens per run. Calculate the monthly token cost for each model.

<SolutionToggle>
- **Daily Token Consumption**: 500 runs * 3,000 tokens = 1,500,000 tokens/day.
- **Monthly Token Consumption**: 1,500,000 * 30 days = 45,000,000 tokens/month (45M tokens).

- **Cost with GPT-4o**: 45 * $2.50 = **$112.50 per month**.
- **Cost with GPT-4o-mini**: 45 * $0.15 = **$6.75 per month**.

`gpt-4o-mini` delivers a **94% cost reduction**. For structured daily briefings where tools supply the heavy data, `gpt-4o-mini` is significantly more economical.
</SolutionToggle>
