Email is ideal for comprehensive, long-form daily briefings. But when you are on the move, instant push notifications delivered directly to your messaging apps (Telegram, Slack, Discord, or WhatsApp) provide immediate convenience.

In this lesson, we create a dedicated **Telegram Bot** and attach it as our fifth agent tool.

```
                  [ Planner AI Agent ]
                    ├── Model: OpenAI Chat Model
                    ├── Memory: Window Buffer Memory
                    └── Tools (Orange Port)
                          ├── [ Google Calendar Tool ] (Reads Schedule)
                          ├── [ OpenWeatherMap Tool ]  (Weather Forecasts)
                          ├── [ SerpAPI Search Tool ]  (Web Intelligence)
                          ├── [ Gmail Tool ]           (Long-form HTML Digest)
                          └── [ Telegram Tool ]        (Instant Mobile Push Notification)
```

## Step 1: Create Your Bot with BotFather

1. Open the Telegram app on your phone or visit [web.telegram.org](https://web.telegram.org).
2. In the Telegram search bar, search for `@BotFather` (the verified official bot with the blue checkmark).
3. Start a conversation with BotFather and send the command:
   ```
   /newbot
   ```
4. Follow the prompts:
   - **Bot Name**: Enter a friendly name, e.g. `n8n Executive Assistant`.
   - **Bot Username**: Enter a unique username ending in `bot`, e.g. `n8n_daily_briefing_bot`.
5. BotFather creates your bot and provides a secret **HTTP API Token** (format: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`). Copy this token and store it securely.

## Step 2: Retrieve Your Personal Chat ID

To allow your bot to send messages to your personal Telegram account, you must initiate the conversation and retrieve your unique **Chat ID**:

1. In Telegram, search for your newly created bot username (`@n8n_daily_briefing_bot`) and click **Start** (or send any test message like `"Hello"`).
2. Open a new browser tab and navigate to the following URL, replacing `<YOUR_BOT_TOKEN>` with your actual token:
   ```
   https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
   ```
3. Inspect the returned JSON payload. Locate the `chat` object and copy the numeric `id`:
   ```json
   {
     "ok": true,
     "result": [
       {
         "message": {
           "from": { "first_name": "Marcus" },
           "chat": {
             "id": 987654321,
             "first_name": "Marcus",
             "type": "private"
           },
           "text": "Hello"
         }
       }
     ]
   }
   ```
   In this example, your Chat ID is `987654321`.

## Step 3: Attach the Telegram Tool in n8n

1. On your canvas, locate the `Planner AI Agent` node.
2. Click the **+** icon beneath the **Tools** port (orange port).
3. Search for **Telegram** and select the **Telegram** tool node.
4. Rename the node to:
   ```
   send_telegram_alert
   ```
5. Configure credentials:
   - Create a new credential under **Telegram API**.
   - Paste your **Access Token** from BotFather and click **Save**.
6. Parameter settings:
   - **Resource**: `Message`
   - **Operation**: `Send Message`
   - **Chat ID**: Paste your numeric Chat ID (`987654321`).
   - **Parse Mode**: Select `Markdown` (or `HTML`).

Click **Execute step** on the tool node: your phone immediately buzzes with a test notification from your bot!

## Step 4: Testing Dual-Channel Delivery

Now execute the complete multi-tool test in the chat interface:
> *"Create a summary of my agenda for tomorrow, check the weather, research the interview company, and send the summary to BOTH my email and my Telegram."*

Observe the execution trace:
1. Agent queries `fetch_calendar_events`.
2. Agent queries `get_weather_forecast`.
3. Agent queries `serpapi_web_search`.
4. Agent calls `send_email_report` with the full HTML table.
5. Agent calls `send_telegram_alert` with a concise markdown summary optimized for mobile screens.
6. Check your phone: your custom Telegram bot has delivered your morning briefing!

<Callout type="info" title="Swapping Telegram for Other Messengers">
The exact same architectural pattern applies if you prefer Discord, Slack, Microsoft Teams, or WhatsApp. Simply attach the corresponding tool node and map the destination channel ID.
</Callout>

<Exercise title="Format Messages for Mobile Constraints">
Telegram has a message limit of 4,096 characters. If an executive digest contains extensive research snippets, sending raw text could truncate or error.

How should you instruct the agent to tailor the Telegram message vs the Gmail report?

<SolutionToggle>
Add a channel differentiation rule to the System Message:
```text
CHANNEL DIFFERENTIATION:
- Gmail: Comprehensive long-form briefing including complete HTML tables, detailed company background, and full forecast metrics.
- Telegram: Concise, high-priority executive bullets (under 1,500 characters) focusing strictly on meeting times, locations, immediate weather conditions, and top 2 news headlines.
```
</SolutionToggle>
</Exercise>
