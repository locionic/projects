ウェブ開発が進歩するにつれて、JavaScriptとTypeScriptはインターネットの主要言語となりました。しかし、ウェブ開発者がゲームエンジニアリングに挑戦したい場合、どうなるでしょうか？Robloxは、7,000万人以上のデイリーアクティブユーザーとクリエイターエコノミーを擁し、世界で最もアクセスしやすいゲームプラットフォームの一つです。

**RobloxはJavaScriptを使用していますか？** いいえ、Robloxは**Luau**を実行します。これは、低遅延のゲームエンジン実行のためにRobloxエンジニアが特別に作成した、Lua 5.1から派生した高性能で厳密に型付けされた言語です。

以下は、一般的なJavaScriptおよびTypeScriptのイディオムを、慣用的なLuauに直接マッピングする、手軽なロゼッタストーンです。

## RobloxはJavaScriptを使用していますか？

いいえ、RobloxはJavaScriptを**使用していません**。Robloxは、Lua 5.1から派生した高速で静的型付けされたスクリプト言語である**Luau**を使用しています。JavaScriptとLuauは、表面的な類似点（関数、ループ、条件ロジック）をいくつか共有していますが、構文、型システム、ランタイム環境が異なる別の言語です。

朗報です。もしあなたがJavaScriptをすでに知っているなら、メンタルモデルの移行は迅速です。ほとんどの制御フローパターン（ループ、条件分岐、関数）は同じように機能します。主な違いは、Luaスタイルのインデックス付け（0ベースではなく1ベース）、配列とオブジェクトを置き換えるテーブルデータ構造、そしてゲームサービス用のRoblox独自のAPIです。

## クイック構文チートシート：JavaScript vs Luau

| JavaScript / TypeScript | Luauの同等物 | 主な違い / 落とし穴 |
| :--- | :--- | :--- |
| `let x = 10; const y = 20;` | `local x = 10; local y = 20` | ネイティブな`const`はありません。すべての変数は`local`でスコープされます |
| `null` または `undefined` | `nil` | 単一の偽の空のプリミティブ |
| `true` / `false` | `true` / `false` | Luauでは、`0`と`""`は**真**です！`nil`と`false`のみが偽です |
| `array[0]` (0-indexed) | `table[1]` (1-indexed) | Luauの配列はインデックス1から始まります |
| `array.length` | `#table` | `#`演算子は連続する配列要素を数えます |
| `array.push(val)` | `table.insert(tbl, val)` | 配列の末尾に追加します |
| `str1 + str2` | `str1 .. str2` | `..`は連結演算子です (`+`は強制的に計算します) |
| `"Hello " + name` / テンプレート文字列 | `string.format("Hello %s!", name)` | または `"Hello " .. name .. "!"` |
| `a === b` と `a !== b` | `a == b` と `a ~= b` | `~=`は等しくない演算子です |
| `&&`, `\|\|`, `!` | `and`, `or`, `not` | キーワードベースのブール論理 |
| `// Comment` / `/* Block */` | `-- Comment` / `--[[ Block ]]` | コメントには二重ハイフンを使用します |
| `setTimeout(fn, 1000)` | `task.delay(1, fn)` | 最新のRobloxタスクスケジューラを使用します |
| `setInterval(fn, 1000)` | `while true do task.wait(1) fn() end` | またはRunService Heartbeatバインディング |
| `target.addEventListener('click', fn)` | `instance.Activated:Connect(fn)` | RBXScriptSignal接続契約 |

## 普遍的なデータ構造：オブジェクトと配列 vs テーブル

JavaScriptでは、順序付きリスト用の配列と、キーと値のペア用のオブジェクトという異なるデータ構造があります。

```javascript
// JavaScript Array
const players = ["Alice", "Bob", "Charlie"];
console.log(players[0]); // "Alice" - 0-indexed!

// JavaScript Object
const playerStats = {
  health: 100,
  mana: 50,
  isAlive: true
};
console.log(playerStats.health); // 100
```

Luauには、唯一のコア複合データ構造である**テーブル**があります。テーブルは配列とハッシュ辞書の両方として機能します。

```lua
-- Luau Array-like Table (1-indexed!)
local players = {"Alice", "Bob", "Charlie"}
print(players[1]) -- "Alice" (Important: Luau is 1-indexed!)

-- Luau Dictionary-like Table
local playerStats = {
    health = 100,
    mana = 50,
    isAlive = true
}
print(playerStats.health) -- 100
```

## オブジェクト指向プログラミング：プロトタイプ vs メタテーブル

現代のJavaScriptでは、クラスはプロトタイプに対するシンタックスシュガーです。

```javascript
class Player {
  constructor(name) {
    this.name = name;
    this.health = 100;
  }
  
  takeDamage(amount) {
    this.health -= amount;
  }
}
const p1 = new Player("Hero");
p1.takeDamage(10);
```

Luauは、**メタテーブル**と`__index`メタメソッドを使用してOOPを実現します。

```lua
local Player = {}
Player.__index = Player -- When a method is missing, lookup in Player table

function Player.new(name)
    local self = setmetatable({}, Player)
    self.name = name
    self.health = 100
    return self
end

function Player:TakeDamage(amount)
    self.health = self.health - amount
end

local p1 = Player.new("Hero")
p1:TakeDamage(10) -- Automatically passes self as first argument
```

## 並行処理：Promise vs コルーチンとタスクライブラリ

Robloxはフレームベースのエンジン（60～120 FPS）で動作します。メインのレンダー スレッドをブロックしないように、Luauは**コルーチン**と組み込みの**タスクライブラリ**（`task.wait`、`task.spawn`、`task.defer`）を使用します。

```lua
-- Luau Task Library (Yielding)
local function loadGameData()
    print("Loading inventory...")
    task.wait(2) -- Yields this thread for 2 seconds without freezing the game
    print("Inventory loaded")
end

task.spawn(loadGameData)
print("This prints immediately without waiting!")
```

## 段階的な型安全性：TypeScript vs Luau `--!strict`

TypeScriptを愛するなら、Luauにはファーストクラスの静的型付けがあります。ファイルの先頭に`--!strict`を追加するだけです。

```lua
--!strict
type PlayerProfile = {
    name: string,
    level: number,
    inventory: {string}
}

local function levelUp(player: PlayerProfile): number
    player.level += 1
    return player.level
end
```

## クライアント・サーバーレプリケーション：Fetch API vs RemoteEvent

ウェブ開発では、フロントエンドのクライアントコンポーネントは、HTTP `fetch()`、REST API、またはWebSocket JSONメッセージを使用してバックエンドサーバーと通信します。Robloxゲームエンジンでは、クライアント（プレイヤーのデバイス）と専用のゲームサーバーは、`RemoteEvent`と`RemoteFunction`インスタンスを使用して状態を同期します。

```lua
-- Server Script (ServerScriptService/RewardSystem.server.lua)
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local GiveRewardEvent = Instance.new("RemoteEvent")
GiveRewardEvent.Name = "GiveReward"
GiveRewardEvent.Parent = ReplicatedStorage

GiveRewardEvent.OnServerEvent:Connect(function(player: Player, rewardAmount: number)
    -- Crucial: Always validate client payload on the server (never trust the client)
    if typeof(rewardAmount) == "number" and rewardAmount > 0 and rewardAmount <= 500 then
        print(string.format("Awarded %d coins to %s", rewardAmount, player.Name))
    end
end)
```

```lua
-- Client Script (StarterPlayerScripts/RewardButton.client.lua)
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local GiveRewardEvent = ReplicatedStorage:WaitForChild("GiveReward") :: RemoteEvent

-- Trigger server action when client UI activates
local function onRequestReward()
    GiveRewardEvent:FireServer(100)
end
```

## roblox-tsという選択肢：Roblox向けに純粋なTypeScriptを記述する

もしあなたが`npm`、Git、VS Codeを使った標準的なTypeScript構文を好むなら、生のLuauを書く必要すらありません。オープンソースの`roblox-ts`コンパイラは、標準的なTypeScriptを完全に最適化されたLuauコードにトランスパイルします。

```bash
# Initialize a modern roblox-ts project
npm create roblox-ts game-project
cd game-project
npm install

# Start the continuous compiler watcher
npx rbxtsc -w
```

`roblox-ts`を使用すると、標準的なTypeScriptクラス、async/awaitのPromise、およびnpmパッケージ（`@rbxts/services`など）を記述でき、これらはRojoを介してRoblox Studioに直接同期される慣用的なLuauファイルに自動的にコンパイルされます。

<FAQ>
  <Question>RobloxはJavaScriptまたはTypeScriptをサポートしていますか？</Question>
  <Answer>
    RobloxはクライアントおよびサーバーエンジンでLuauをネイティブに実行します。しかし、ウェブ開発者はTypeScriptを記述し、人気のあるオープンソースコンパイラroblox-tsを使用して慣用的なLuauにコンパイルできます。
  </Answer>

  <Question>Luauが0ベースではなく1ベースのインデックスを使用するのはなぜですか？</Question>
  <Answer>
    LuauはLua 5.1から1ベースのインデックスを継承しています。Lua 5.1は、最初の項目が要素1である非プログラマーや数学的表記法のために設計されました。
  </Answer>

  <Question>Robloxのtask.wait()とwait()の違いは何ですか？</Question>
  <Answer>
    レガシーな`wait()`は30Hzにスロットルされ、スケジューラパイプラインの遅延に悩まされる可能性があります。現代の`task.wait()`はRobloxのHeartbeatイベント（60Hz以上で実行）と同期しており、より高速で決定論的です。
  </Answer>

  <Question>Luauでconstの不変性をどのように扱いますか？</Question>
  <Answer>
    Luauには`const`キーワードがありません。すべての変数は`local`で宣言されます。テーブルの場合、テーブルを`table.freeze(myTable)`でラップすることで、実行時に不変性を強制できます。
  </Answer>
</FAQ>
