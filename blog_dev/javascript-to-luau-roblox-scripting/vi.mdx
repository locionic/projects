Khi phát triển web ngày càng tiến hóa, JavaScript và TypeScript đã trở thành những ngôn ngữ thống trị trên internet. Nhưng điều gì sẽ xảy ra khi các nhà phát triển web muốn chuyển sang kỹ thuật trò chơi? Roblox, với hơn 70 triệu người dùng hoạt động hàng ngày và nền kinh tế sáng tạo, là một trong những nền tảng trò chơi dễ tiếp cận nhất trên thế giới.

**Roblox có sử dụng JavaScript không?** Không; Roblox thực thi **Luau**, một ngôn ngữ phái sinh hiệu suất cao, kiểu chặt chẽ của Lua 5.1 được các kỹ sư Roblox tạo ra đặc biệt để thực thi công cụ trò chơi có độ trễ thấp.

Dưới đây là bảng đối chiếu nhanh chóng của bạn, ánh xạ các thành ngữ JavaScript và TypeScript phổ biến trực tiếp sang Luau chuẩn.

## Roblox có sử dụng JavaScript không?

Không — Roblox **không** sử dụng JavaScript. Roblox sử dụng **Luau**, một ngôn ngữ kịch bản nhanh, kiểu tĩnh được phát triển từ Lua 5.1. Mặc dù JavaScript và Luau có một số điểm tương đồng bề ngoài (hàm, vòng lặp, logic điều kiện), chúng là những ngôn ngữ khác nhau với cú pháp, hệ thống kiểu và môi trường runtime khác nhau.

Tin tốt là: nếu bạn đã biết JavaScript, việc chuyển đổi mô hình tư duy sẽ rất nhanh. Hầu hết các mẫu luồng điều khiển (vòng lặp, điều kiện, hàm) hoạt động theo cùng một cách. Sự khác biệt chính là cách đánh chỉ mục kiểu Lua (bắt đầu từ 1, không phải 0), cấu trúc dữ liệu bảng (thay thế mảng và đối tượng), và các API riêng của Roblox cho các dịch vụ trò chơi.

## Bảng tra cứu cú pháp nhanh: JavaScript vs Luau

| JavaScript / TypeScript | Luau Tương đương | Khác biệt chính / Lưu ý |
| :--- | :--- | :--- |
| `let x = 10; const y = 20;` | `local x = 10; local y = 20` | Không có `const` gốc; tất cả các biến được định phạm vi với `local` |
| `null` hoặc `undefined` | `nil` | Một giá trị nguyên thủy rỗng falsy duy nhất |
| `true` / `false` | `true` / `false` | Trong Luau, `0` và `""` là **truthy**! Chỉ `nil` và `false` là falsy |
| `array[0]` (chỉ mục 0) | `table[1]` (chỉ mục 1) | Mảng Luau bắt đầu từ chỉ mục 1 |
| `array.length` | `#table` | Toán tử `#` đếm các phần tử mảng liên tiếp |
| `array.push(val)` | `table.insert(tbl, val)` | Nối vào cuối mảng |
| `str1 + str2` | `str1 .. str2` | `..` là toán tử nối chuỗi (`+` buộc toán học) |
| `"Hello " + name` / chuỗi mẫu | `string.format("Hello %s!", name)` | Hoặc `"Hello " .. name .. "!"` |
| `a === b` và `a !== b` | `a == b` và `a ~= b` | `~=` là toán tử không bằng |
| `&&`, `\|\|`, `!` | `and`, `or`, `not` | Logic boolean dựa trên từ khóa |
| `// Comment` / `/* Block */` | `-- Comment` / `--[[ Block ]]` | Dấu gạch ngang kép cho bình luận |
| `setTimeout(fn, 1000)` | `task.delay(1, fn)` | Sử dụng bộ lập lịch tác vụ Roblox hiện đại |
| `setInterval(fn, 1000)` | `while true do task.wait(1) fn() end` | Hoặc ràng buộc RunService Heartbeat |
| `target.addEventListener('click', fn)` | `instance.Activated:Connect(fn)` | Hợp đồng kết nối RBXScriptSignal |

## Cấu trúc dữ liệu phổ quát: Đối tượng & Mảng vs Bảng

Trong JavaScript, bạn có các cấu trúc dữ liệu riêng biệt: Mảng cho danh sách có thứ tự và Đối tượng cho các cặp khóa-giá trị.

```javascript
// JavaScript Array
const players = ["Alice", "Bob", "Charlie"];
console.log(players[0]); // "Alice" - 0-indexed!

// JavaScript Object
const playerStats = {
  health: 100,
  mana: 50,
  isAlive: true
};
console.log(playerStats.health); // 100
```

Trong Luau, chỉ có một cấu trúc dữ liệu tổng hợp cốt lõi: **Bảng**. Bảng đóng vai trò vừa là mảng vừa là từ điển băm.

```lua
-- Luau Array-like Table (1-indexed!)
local players = {"Alice", "Bob", "Charlie"}
print(players[1]) -- "Alice" (Important: Luau is 1-indexed!)

-- Luau Dictionary-like Table
local playerStats = {
    health = 100,
    mana = 50,
    isAlive = true
}
print(playerStats.health) -- 100
```

## Lập trình hướng đối tượng: Prototypes vs Metatables

Trong JavaScript hiện đại, các lớp là đường cú pháp trên các prototype:

```javascript
class Player {
  constructor(name) {
    this.name = name;
    this.health = 100;
  }
  
  takeDamage(amount) {
    this.health -= amount;
  }
}
const p1 = new Player("Hero");
p1.takeDamage(10);
```

Luau đạt được OOP bằng cách sử dụng **Metatables** và metamethod `__index`:

```lua
local Player = {}
Player.__index = Player -- When a method is missing, lookup in Player table

function Player.new(name)
    local self = setmetatable({}, Player)
    self.name = name
    self.health = 100
    return self
end

function Player:TakeDamage(amount)
    self.health = self.health - amount
end

local p1 = Player.new("Hero")
p1:TakeDamage(10) -- Automatically passes self as first argument
```

## Đồng thời: Promises vs Coroutines & Thư viện Task

Roblox chạy trên một engine dựa trên khung hình (60–120 FPS). Để tránh chặn luồng render chính, Luau sử dụng **Coroutines** và **Thư viện Task** tích hợp (`task.wait`, `task.spawn`, `task.defer`).

```lua
-- Luau Task Library (Yielding)
local function loadGameData()
    print("Loading inventory...")
    task.wait(2) -- Yields this thread for 2 seconds without freezing the game
    print("Inventory loaded")
end

task.spawn(loadGameData)
print("This prints immediately without waiting!")
```

## An toàn kiểu dần dần: TypeScript vs Luau `--!strict`

Nếu bạn yêu thích TypeScript, Luau có kiểu tĩnh hạng nhất. Chỉ cần thêm `--!strict` ở đầu tệp của bạn:

```lua
--!strict
type PlayerProfile = {
    name: string,
    level: number,
    inventory: {string}
}

local function levelUp(player: PlayerProfile): number
    player.level += 1
    return player.level
end
```

## Sao chép Client-Server: Fetch APIs vs RemoteEvents

Trong phát triển web, các thành phần client frontend giao tiếp với các máy chủ backend bằng HTTP `fetch()`, REST API hoặc tin nhắn JSON WebSocket. Trong các engine trò chơi Roblox, client (thiết bị của người chơi) và máy chủ trò chơi chuyên dụng đồng bộ hóa trạng thái bằng cách sử dụng các thể hiện `RemoteEvent` và `RemoteFunction`.

```lua
-- Server Script (ServerScriptService/RewardSystem.server.lua)
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local GiveRewardEvent = Instance.new("RemoteEvent")
GiveRewardEvent.Name = "GiveReward"
GiveRewardEvent.Parent = ReplicatedStorage

GiveRewardEvent.OnServerEvent:Connect(function(player: Player, rewardAmount: number)
    -- Crucial: Always validate client payload on the server (never trust the client)
    if typeof(rewardAmount) == "number" and rewardAmount > 0 and rewardAmount <= 500 then
        print(string.format("Awarded %d coins to %s", rewardAmount, player.Name))
    end
end)
```

```lua
-- Client Script (StarterPlayerScripts/RewardButton.client.lua)
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local GiveRewardEvent = ReplicatedStorage:WaitForChild("GiveReward") :: RemoteEvent

-- Trigger server action when client UI activates
local function onRequestReward()
    GiveRewardEvent:FireServer(100)
end
```

## Giải pháp thay thế roblox-ts: Viết TypeScript thuần túy cho Roblox

Nếu bạn thích giữ cú pháp TypeScript tiêu chuẩn với `npm`, Git và VS Code, bạn thậm chí không cần phải viết Luau thô. Trình biên dịch mã nguồn mở `roblox-ts` chuyển đổi TypeScript tiêu chuẩn thành mã Luau được tối ưu hóa hoàn toàn.

```bash
# Initialize a modern roblox-ts project
npm create roblox-ts game-project
cd game-project
npm install

# Start the continuous compiler watcher
npx rbxtsc -w
```

Với `roblox-ts`, bạn viết các lớp TypeScript tiêu chuẩn, các promise async/await và các gói npm (như `@rbxts/services`), chúng sẽ tự động biên dịch thành các tệp Luau chuẩn được đồng bộ hóa trực tiếp vào Roblox Studio thông qua Rojo.

  <Question>Roblox có hỗ trợ JavaScript hay TypeScript không?</Question>
  <Answer>
    Roblox chạy Luau nguyên bản trên các engine client và server. Tuy nhiên, các nhà phát triển web có thể viết TypeScript và biên dịch nó thành Luau chuẩn bằng cách sử dụng trình biên dịch mã nguồn mở phổ biến roblox-ts.

  <Question>Sự khác biệt giữa task.wait() và wait() trong Roblox là gì?</Question>
  <Answer>
    `wait()` cũ bị giới hạn xuống 30Hz và có thể bị trễ đường ống của bộ lập lịch. `task.wait()` hiện đại được đồng bộ hóa với sự kiện Heartbeat của Roblox (chạy ở 60Hz+), làm cho nó nhanh hơn và xác định hơn.
  </Answer>
