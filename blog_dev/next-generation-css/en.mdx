# Next-generation CSS: Container queries and more

Responsive web design has relied on media queries for over a decade. While media queries allow styling based on the viewport size, they fall short in component-driven architectures where a component needs to respond to the size of its parent container, not the entire screen.

## Container Queries
Container queries solve this fundamental flaw. By defining a container and querying its dimensions, developers can build truly modular, responsive components. A card component can now style itself differently when placed in a narrow sidebar versus a wide main content area, all without writing complex JavaScript or duplicating CSS classes.

## The :has() Pseudo-Class
Another revolutionary addition to CSS is the `:has()` pseudo-class. Often referred to as the "parent selector," `:has()` allows developers to style a parent element based on its descendants or subsequent siblings. This unlocks powerful declarative styling patterns, such as highlighting a form group only when an input inside it is invalid, significantly reducing the need for JavaScript DOM manipulation for UI states.
