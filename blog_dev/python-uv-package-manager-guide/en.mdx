Python's packaging ecosystem has long been a source of frustration. From `pip` to `Pipenv`, and `Poetry` to `PDM`, developers have struggled with slow resolution times and fragmented tooling. Enter **uv**, a unified, incredibly fast Python package manager and resolver written in Rust by Astral (the creators of Ruff).

In this tutorial, we'll explore why uv is taking the Python world by storm, see some benchmarks, and walk through how to migrate your existing projects. If you're new to Python environments, check out our [introductory guide to Python environments](/en/blog/python-env) first.

## Why uv? Speed and Simplicity

The most striking feature of uv is its raw performance. It is built in Rust, leveraging heavy concurrency and aggressive caching to resolve and install dependencies up to 10-100x faster than traditional tools.

### Performance Benchmarks

Here's a comparison of dependency resolution and installation speeds across popular Python package managers (lower is better).

| Tool | Resolution Time (Cold Cache) | Installation Time (Warm Cache) | Written In |
|---|---|---|---|
| `pip` | ~25.0s | ~5.0s | Python |
| `Poetry` | ~45.0s | ~12.0s | Python |
| `PDM` | ~20.0s | ~4.5s | Python |
| `uv` | **~0.2s** | **~0.05s** | Rust |

## How uv Works Under the Hood

Unlike Python-based resolvers which are bound by the GIL (Global Interpreter Lock) and network I/O bottlenecks, uv resolves dependencies using Rust's fearless concurrency.

## Migrating to uv

Migrating from `pip` or `Poetry` to `uv` is incredibly straightforward since `uv` implements a pip-compatible interface while also supporting `pyproject.toml` standards.

<Stepper>
  <Step title="1. Install uv">
    You can install uv using curl, pip, or homebrew. The recommended way is via the standalone installer:
    \`\`\`bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    \`\`\`
  </Step>
  <Step title="2. Create a Virtual Environment">
    uv has its own lightning-fast virtual environment creator that drops in as a replacement for \`python -m venv\`.
    \`\`\`bash
    uv venv
    source .venv/bin/activate
    \`\`\`
  </Step>
  <Step title="3. Install Dependencies">
    If you have an existing \`requirements.txt\`, you can install it instantly:
    \`\`\`bash
    uv pip install -r requirements.txt
    \`\`\`
    If you're using a \`pyproject.toml\`, uv can compile and sync your dependencies:
    \`\`\`bash
    uv pip compile pyproject.toml -o requirements.txt
    uv pip sync requirements.txt
    \`\`\`
  </Step>
</Stepper>
