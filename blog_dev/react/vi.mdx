## React là gì?

React là một thư viện JavaScript dùng để xây dựng giao diện người dùng theo mô hình **component**.

<Callout type="idea" title="Mô hình Component">
Hãy tưởng tượng component như những mảnh ghép LEGO. Bạn tạo ra các mảnh nhỏ, tái sử dụng được và ghép chúng lại thành một giao diện hoàn chỉnh!
</Callout>

```jsx
function ChaoMung({ ten }) {
  return <h1>Xin chào, {ten}!</h1>;
}
```

## Quản lý State với `useState`

`useState` lưu trữ dữ liệu ngay trong **RAM của trình duyệt**.

<Callout type="warning" title="So sánh địa chỉ ô nhớ">
React so sánh state dựa trên **địa chỉ ô nhớ**. Sửa trực tiếp object sẽ không làm thay đổi địa chỉ của nó, nên React sẽ không re-render! Luôn nhớ copy object/array.
</Callout>

<Stepper>
  <Step title="Cách làm sai">
    Gọi `setDem(dem + 1)` nhiều lần liên tiếp sẽ dùng lại giá trị cũ (stale snapshot).
    ```jsx
    setDem(dem + 1); // ❌
    ```
  </Step>
  <Step title="Cách làm đúng">
    Sử dụng dạng callback để đảm bảo bạn luôn lấy được giá trị mới nhất!
    ```jsx
    setDem(prev => prev + 1); // ✅
    ```
  </Step>
</Stepper>

## Xử lý Side Effects với `useEffect`

Side effects là những việc như gọi API hay đặt timer.

<Callout type="danger" title="Hàm Cleanup (Dọn dẹp)">
Đoạn `return () => ...` KHÔNG phải là code chạy tuần tự. Bạn đang "gửi gắm" một hàm cho React để nó chạy sau này (khi dependencies thay đổi hoặc khi unmount).
</Callout>

```jsx
useEffect(() => {
  const timer = setTimeout(() => console.log('Ping!'), 1000);
  return () => clearTimeout(timer); // 🧹 Cleanup
}, []);
```

## Tránh Prop Drilling với `useContext`

Chán nản vì phải truyền props qua 5 tầng component? Context chính là cứu tinh của bạn.

<Callout type="info" title="Cẩn thận với Re-render!">
Mọi component dùng context đều bị re-render khi *bất kỳ* giá trị nào trong đó thay đổi. Với global state phức tạp, hãy cân nhắc sử dụng Zustand!
</Callout>

---

## Next.js App Router: Cách tiếp cận hiện đại

Next.js thay đổi luật chơi: mặc định, mọi thứ đều là **Server Component**.

<Stepper>
  <Step title="Server Components">
    Chạy trên server. Tuyệt vời cho SEO và fetch data ban đầu. Không dùng được `useState` hay `useEffect`.
  </Step>
  <Step title="Client Components">
    Thêm `"use client"` ở đầu file. Dùng khi cần tương tác, lắng nghe sự kiện, và sử dụng hooks.
  </Step>
</Stepper>

<Callout type="idea" title="Sơ đồ quyết định nhanh">
- State giao diện nội bộ? `useState`
- State toàn ứng dụng? `Zustand`
- Fetch data & caching? `TanStack Query`
- SEO & data tĩnh? `Next.js Server Components`
</Callout>
