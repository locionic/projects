# Beyond PyTorch

JAX brings automatic differentiation and XLA (Accelerated Linear Algebra) compilation to NumPy-like code.

## JIT Compilation

The power of JAX lies in its `jit` (Just-In-Time) compilation.

```python
import jax.numpy as jnp
from jax import jit

@jit
def fast_function(x):
    return jnp.dot(x, x)
```

## TPU Utilization

When run on TPUs, JAX programs map matrix multiplications perfectly to the systolic arrays of the TPU.

## Conclusion

For massive-scale models, XLA and JAX represent the cutting edge of performance engineering.
