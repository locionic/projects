# The Rise of Vector Databases

Vector embeddings are the core of modern AI. Instead of using a specialized vector database, `pgvector` brings vector search directly into PostgreSQL.

## HNSW Indexes

To scale vector search, `pgvector` introduced HNSW (Hierarchical Navigable Small World) indexes.

```sql
CREATE INDEX ON items USING hnsw (embedding vector_cosine_ops);
```
