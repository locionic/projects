# Introduction

WebAssembly (Wasm) combined with Rust offers unparalleled performance in the browser. In React 19, the integration is smoother than ever. 

## Setting up Rust

First, we compile Rust to WebAssembly using `wasm-pack`. 

```bash
wasm-pack build --target web
```
