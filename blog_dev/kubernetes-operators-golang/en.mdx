# Extending Kubernetes

Operators allow you to codify operational knowledge into software.

## Kubebuilder

Using `kubebuilder`, scaffolding a new project is straightforward.

```bash
kubebuilder init --domain locionic.com --repo locionic.com/operator
```

## The Reconcile Loop

The heart of an operator is the Reconcile function. It ensures the current state matches the desired state.

```go
func (r *MyReconciler) Reconcile(ctx context.Context, req ctrl.Request) (ctrl.Result, error) {
    // Logic here
}
```
