# The End of useMemo

The React Compiler analyzes your code and automatically memoizes values, rendering `useMemo` and `useCallback` largely obsolete.

## Abstract Syntax Trees

The compiler operates by parsing JSX into an AST, running data-flow analysis, and injecting memoization hooks implicitly.

## How it transforms code

A simple component:
```javascript
function MyComponent({ data }) {
    const processed = heavyProcessing(data);
    return <div>{processed}</div>;
}
```
Is transformed to cache `processed` if `data` hasn't changed.

## Conclusion

The compiler represents a massive shift in React DX, bringing it closer to compiled frameworks like Svelte while retaining the React model.
