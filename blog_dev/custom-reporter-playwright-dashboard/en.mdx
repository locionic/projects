Building a custom reporter for Playwright is the most effective way to stream live test automation results into your own Next.js dashboard. Instead of relying on static HTML reports or paying for third-party services, you can write a dedicated reporter that captures exact test metrics and posts them directly to your backend.

In this guide, you will learn exactly how to implement a custom JSON reporter in Playwright and build the receiving API route in Next.js. We cover the entire pipeline, from the `Reporter` interface to the database insertion.

## Why Should You Build a Custom Dashboard?

![Custom Dashboard Analytics](/static/images/why-build-custom-dashboard.avif)

You should build a custom dashboard because standard HTML reporters lack historical tracking and team-wide visibility. When you have a team of developers running thousands of tests every day, you need a centralized, live view of your automation health.

A custom Playwright reporter allows you to capture specific data points—like test duration, retry counts, and precise error messages—and send them to a database. A Next.js application can then visualize this data in real time. This keeps your testing data private, avoids vendor lock-in, and gives you total control over how you analyze test stability over time.

## How Do You Write the Playwright Reporter?

![Playwright Reporter Code Editor](/static/images/how-to-write-playwright-reporter.avif)

You write the Playwright reporter by extending the built-in `Reporter` interface and implementing the lifecycle methods. Playwright exposes hooks like `onTestEnd` and `onEnd`, which allow you to intercept test results as they happen.

Create a file named `dashboard-reporter.ts` in your Playwright project. Here is the implementation that collects the results and posts them to your Next.js application:

```typescript
import { Reporter, TestCase, TestResult, FullResult } from '@playwright/test/reporter';

class NextjsDashboardReporter implements Reporter {
  private results: any[] = [];

  onTestEnd(test: TestCase, result: TestResult) {
    this.results.push({
      title: test.title,
      status: result.status,
      duration: result.duration,
      errors: result.errors,
    });
  }

  async onEnd(result: FullResult) {
    console.log(`Test run finished with status: ${result.status}`);
    
    await fetch('https://your-nextjs-dashboard.com/api/reports', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        status: result.status,
        tests: this.results,
        timestamp: new Date().toISOString(),
      }),
    });
  }
}

export default NextjsDashboardReporter;
```

Once you have written this class, update your `playwright.config.ts` to use it. You simply add `['./dashboard-reporter.ts']` to your `reporter` array.

## How Do You Create the Next.js Receiver?

![Next.js API Route Architecture](/static/images/how-to-create-nextjs-receiver.avif)

You create the Next.js receiver by defining an API route that accepts POST requests and processes the incoming JSON payload. This endpoint acts as the bridge between your test runs and your database.

If you are using the Next.js App Router, create a file at `app/api/reports/route.ts`. The implementation looks like this:

```typescript
import { NextResponse } from 'next/server';

export async function POST(request: Request) {
  const data = await request.json();
  
  console.log(`Received test report with status: ${data.status}`);
  // Insert into your database (e.g., PostgreSQL via Prisma)
  // await prisma.report.create({ data: { ... } })
  
  return NextResponse.json({ success: true, message: 'Report saved' });
}
```

This route parses the incoming payload and logs the status. In a production environment, you will insert the data into a database like PostgreSQL. From there, you can build React components to fetch this data and display live charts. ## Frequently Asked Questions


  ### How much does it cost to run a custom Playwright dashboard?
  Running a custom dashboard costs very little. You only pay for the Next.js hosting and the database. If you use a platform like Vercel and a managed PostgreSQL database, your monthly costs can be close to zero for a small team.

  ### Can I send attachments like screenshots to Next.js?
  Yes, you can send attachments. However, instead of sending large binary files in the JSON payload, it is better to upload the screenshots to an S3 bucket during the test run and send the URL in the reporter payload.

  ### Does a custom reporter slow down the test execution?
  No, the reporter runs asynchronously. The actual tests execute at their normal speed, and the data aggregation happens in the background or during the `onEnd` hook after the tests have finished.

  ### Is this compatible with Playwright sharding?
  Yes, it is compatible with sharding. Each shard will send its own report to the Next.js endpoint. You can group the results in your database by passing a shared run ID via environment variables to all shards.
