Hey, I'm **Locionic**. Welcome to my engineering notebook.

I'm a full-stack and systems engineer obsessed with building fast, resilient web applications, demystifying the Linux kernel, and crafting offline-first browser developer tools. 

### Why this blog exists

Most developer blogs either read like marketing brochures or copy-paste the first paragraph of an official tutorial. I started this site to write the articles I wish existed when production broke at 3 AM:

- **Zero Hand-Waving:** Every guide includes actual failure modes, memory profiles, and copy-pasteable configs that were tested in real environments.
- **Relatable War Stories:** From tracking down mysterious 2-minute login hangs on Ubuntu to fixing cryptic Minified React Error #418s, I share the messy debugging journeys that textbooks skip.
- **Free, Private In-Browser Tools:** 21 client-side utilities (JWT debuggers, Cron builders, SLO burn-rate calculators) that run 100% offline in your browser with zero telemetry tracking.

When I'm not writing or profiling SQL queries, you'll find me contributing to open-source systems, experimenting with local LLMs, or drinking way too much espresso.
