## Overview

NEURON is a full-stack multi-model AI platform that lets you query several LLMs side-by-side, save conversation history, and run multi-agent pipelines for blog and book drafting. Built on Next.js 16 (App Router) with Supabase for authentication and PostgreSQL storage, Stripe for subscriptions, and Pollinations.ai as the model gateway—no private API keys required.

## Key Features & Architecture

- 🧠 **Multi-Model Comparison**: Fire a single prompt simultaneously across several LLMs and analyze their output, token speed, and reasoning side-by-side.
- 💬 **Real-Time Token Streaming**: Real-time streaming with automatic session persistence to Supabase and shareable permalinks (`/chat/[slug]`).
- 🤖 **Autonomous Multi-Agent Pipelines**: Chain specialized Writer and Reviewer agents for drafting technical essays, highlighting AI-sounding text, and suggesting structural improvements.
- 🔐 **Zero-Vendor Lock-in Auth**: Email/password authentication, callback handling, and server-side cookie sessions via Supabase.
- 💳 **Stripe Subscriptions**: Integrated Stripe checkout for Pro ($9/mo) and Team ($29/mo) tiers with automated webhook status synchronization.
- 🖼️ **Multimodal Generation**: In-browser text-to-speech (TTS) audio narration and image generation endpoints.

## Tech Stack

* **Framework:** Next.js 16 (App Router)
* **Backend & Auth:** Supabase (PostgreSQL, Row Level Security)
* **Model Gateway:** Pollinations.ai API
* **Payments:** Stripe Checkout & Webhooks
* **Styling:** Tailwind CSS, Cyberpunk Theme Token Palette
* **Hosting:** Netlify / Vercel Edge
