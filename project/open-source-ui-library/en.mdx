# LocUI: Accessible React Component Library

Building accessible applications shouldn't compromise on design. LocUI bridges that gap.

## Implementation

The components are styled with TailwindCSS and strictly adhere to WAI-ARIA guidelines.

```tsx
import { Button } from 'locui';

export default function App() {
  return (
    <Button aria-label="Submit Form" variant="primary">
      Submit
    </Button>
  );
}
```

## Features
- Fully accessible out of the box
- Highly customizable with Tailwind classes
- Open-source and community driven
