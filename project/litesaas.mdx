## Overview

Most modern SaaS templates default to managed database infrastructure (Supabase, Neon, PlanetScale) that incurs recurring subscription tiers and egress costs before reaching profitability.

**LiteSaaS** is an open-source, production-grade Next.js 15 starter kit engineered for solo developers and founders who want to run high-throughput, zero-database-cost SaaS products. By combining embedded SQLite in Write-Ahead Logging (WAL) mode with continuous S3 streaming replication via Litestream, LiteSaaS delivers sub-millisecond query responses and automated disaster recovery on a $4/month VPS.

## Core Engineering Features

### 1. High-Concurrency SQLite with WAL Mode
* Configured with `PRAGMA journal_mode = WAL`, `PRAGMA synchronous = NORMAL`, and `PRAGMA busy_timeout = 5000`.
* Allows unlimited concurrent readers while a background writer commits transactions without database locking bottlenecks.

### 2. Continuous S3 Disaster Recovery via Litestream
* Built-in **Litestream** background process continuously replicates WAL frames to Cloudflare R2, AWS S3, or MinIO.
* Provides near-zero Recovery Point Objective (RPO) and instant point-in-time database restoration upon server migration or crash.

### 3. Self-Hosted Session Authentication
* Zero third-party auth lock-in: secure, HTTP-only, SameSite cookie sessions with `argon2id` / `bcrypt` password hashing.
* Eliminates monthly per-active-user auth vendor bills (Auth0, Clerk).

## Tech Stack

* **Framework:** Next.js 15 (App Router, Server Actions)
* **Database:** SQLite (better-sqlite3) with Litestream
* **ORM:** Drizzle ORM
* **Styling:** Tailwind CSS, Lucide Icons
* **Deployment:** Docker, Railway, Fly.io, or VPS ($4/mo)
