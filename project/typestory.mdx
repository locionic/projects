## Overview

Most typing tutors train muscle memory through random strings or isolated word collections. While effective for raw finger mechanics, they disconnect the typist from authentic syntax, domain-specific vocabulary, and conceptual flow.

**TypeStory** is an open-access touch-typing platform built for software engineers and learners. It combines touch-typing ergonomics with real-world technical literature (Distributed Systems, RAG Pipelines, Cloud Architecture, and Classic Essays), accompanied by zero-latency mechanical keyboard audio synthesis and native client-side speech narration.

## Key Features & Technical Highlights

### 1. Mechanical Switch Audio Synthesizer (Web Audio API)
* Uses pure browser-native oscillators, band-pass filters, and gain envelopes via the **HTML5 Web Audio API**.
* Synthesizes authentic acoustic profiles for **Cherry MX Blue (clicky)**, **Cherry MX Brown (tactile)**, and **Bubble Pop**.
* **Zero audio asset downloads:** Eliminates audio buffering lag, CDN dependencies, and browser click delay.

### 2. Contextual Engineering & Story Literature
* Practice typing with authentic distributed systems documentation, algorithms, speeches, and essays (Raft consensus, Docker caching, Redis internals, Steve Jobs commencement address).
* Paragraph-by-paragraph flow with real-time Words Per Minute (WPM), accuracy tracking, and instant backspace error recovery.
* Trilingual English-Vietnamese glossary tooltips with phonetics and parts of speech.

### 3. Native Client-Side Text-To-Speech (TTS)
* Integrated browser SpeechSynthesis API with variable playback speed (0.75x to 1.5x).
* Enables typists to hear technical pronunciation before or during typing drills with zero cloud API latency or ongoing token fees.

### 4. Touch-Typing Virtual Keyboard & Finger Zones
* Dynamic on-screen QWERTY map highlighting active target keys, Shift modifiers, and tactile home-row bumps (`F` and `J`).
* Five color-coded ergonomic finger zones (Pinky, Ring, Middle, Index, Thumb) providing real-time finger placement recommendations.

### 5. Performance Analytics & RFC 4180 CSV Export
* Automatic localStorage persistence for session speed, accuracy averages, and consecutive daily streak counters (`🔥 X Days`).
* Speed Trend SVG sparkline visualizing progress across sessions with marked axes.
* RFC 4180-compliant CSV export with UTF-8 BOM encoding for seamless analysis in Excel and Google Sheets.
