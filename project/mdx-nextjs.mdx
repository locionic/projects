## Short Explanation

A modern blog and portfolio platform built with Next.js App Router, MDX content via Contentlayer, and Tailwind CSS.

Some of the features include:

- 📝 MDX-powered content with syntax highlighting and math rendering
- 🌐 Multi-locale support (English, Vietnamese, Japanese)
- 🔍 Full-text search powered by kbar
- 🎨 Dark / light theme toggle
- 📊 Google AdSense integration
- 🗂️ Tag-based content organization with crawl-budget protection
- ⚡ Vercel Edge Network deployment with ISR caching
