## Overview

High-converting landing pages for technical developer tools demand aesthetic perfection: deep dark-mode palettes, glassmorphism, responsive interactive terminals, and flawless Core Web Vitals.

**Apex SaaS** is an open-source, Figma-grade Next.js 15 landing page starter kit designed for solo founders, engineers, and AI startups. Inspired by the sleek design systems of Linear and Vercel, it ships with interactive code sandboxes, dynamic pricing matrices, and bento-grid feature showcases out of the box.

### 1. Obsidian & Glassmorphic Visual System
* Hand-crafted CSS token palette centered on deep obsidian backgrounds (`#090d16`), subtle hairline borders (`border-white/10`), and radiant radial glows.
* Micro-interactions built with zero heavy animation libraries, keeping JavaScript payload under 45 KB.

### 2. Multi-Language Interactive Code Terminal
* Live interactive tabbed code switcher supporting **TypeScript**, **Python**, and **cURL**.
* Simulates real-time API request execution and response formatting directly in the browser.

### 3. Complete Landing Page & Bento Grid Showcase
* High-density modular bento cards highlighting autonomous AI agents, global edge caching, and end-to-end type safety.
* Includes testimonial proof cards, developer stats, and dynamic interactive pricing tiers.
