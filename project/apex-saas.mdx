## Short Explanation

Apex SaaS is an open-source, Figma-inspired landing page template and starter kit built with Next.js 15 App Router, TypeScript, and Tailwind CSS v4. Designed for solo founders and engineering teams building developer tools and AI SaaS products.

Some of the features implemented include:

- 🎨 Linear & Vercel Aesthetic: Deep obsidian dark mode (#090d16), subtle glowing gradients, and hairline glassmorphic cards.

- 💻 Interactive Code Terminal: Live switcher supporting TypeScript, Python, and cURL with simulated real-time sandboxed execution.

- 🧩 Bento Grid Architecture: Modular layout showcasing autonomous AI agent loops, global edge caching, and end-to-end type safety.

- 💳 Interactive Pricing Matrix: Dynamic monthly vs annual toggle with 20% discount calculation and celebratory feedback.

- 💬 Testimonial Wall of Love: Social proof cards with engineer roles and company verification.

- ⚡ 100/100 Lighthouse Performance: Zero heavy UI library bloat, pure React primitives, and instant Vercel edge deployment.

- 📦 1-Click Deploy: Fully configured for instant cloning and deployment to Vercel and Netlify.
