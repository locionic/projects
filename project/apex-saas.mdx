## The Frontend Performance Crisis in Modern Landing Pages

Most contemporary SaaS and AI startup templates suffer from severe runtime bloat:

1. **Heavy Animation Runtimes:** Bundling heavy JavaScript animation suites (Three.js, heavy Framer Motion bundles, canvas particle meshes) pushes initial bundle payloads past **400–800 KB**.
2. **Main Thread Blocking:** Unoptimized canvas loops and reactive state listeners starve the main thread, resulting in **Total Blocking Time (TBT) > 600 ms** and poor Interaction to Next Paint (INP) on mobile hardware.
3. **Cumulative Layout Shift (CLS):** Unconstrained lazy-loaded cards and unstabilized hero graphics cause jarring layout jumps during initial page paint.

**Apex SaaS** is an open-source design-engineering reference template engineered to prove that a high-conversion, Linear/Vercel-grade visual aesthetic can be achieved with **zero JavaScript animation dependencies** and **100/100 Google Lighthouse scores**.

## Design System & Architecture

```
┌────────────────────────────────────────────────────────────────────────┐
│                   Apex SaaS Design-Engineering Rules                   │
├────────────────────────────────────────────────────────────────────────┤
│ 1. Zero Heavy Animation Libraries: 100% CSS Transitions & Keyframes    │
│ 2. Sub-45KB Total JavaScript Payload: Instant First Contentful Paint   │
│ 3. Deep Obsidian Palette: #090d16 Canvas with Radiant Hairline Borders │
│ 4. Accessible Primitives: Native ARIA Semantics for Tabs & Pricing     │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. Obsidian Token Palette & Micro-Interactions
* Built around a strict, high-contrast dark-mode palette:
  - Background canvas: Deep obsidian (`#090d16`).
  - Card surfaces: Subtle translucency with hairline borders (`border-white/10`).
  - Radial ambient accents: Low-opacity GPU-accelerated gradients (`radial-gradient(ellipse at top, ...)`).
* Micro-interactions (hover scales, card illumination, button press feedback) are handled via pure CSS pseudo-classes, eliminating reactive React state re-renders during mouse movements.

### 2. Multi-Language Interactive Code Terminal
* Features an interactive tabbed syntax playground supporting **TypeScript**, **Python**, and **cURL**.
* **Zero Runtime Eval:** Uses pre-compiled syntax token trees to simulate live API responses instantly without exposing client-side execution boundaries or pulling in heavy client-side Prism/Monaco bundles.

### 3. Dynamic Pricing Calculator
* An accessible annual vs. monthly billing toggle that calculates immediate 20% annual discount savings.
* Built using native HTML radio group semantics with keyboard navigation support (`ArrowLeft` / `ArrowRight`) and smooth CSS number transitions.
